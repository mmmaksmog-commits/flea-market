# 🏺 Барахолка

**7 дней на блошином рынке: торгуйтесь, распознавайте подделки и перепродавайте с выгодой.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/flea-market/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- 5 характеров продавцов и 4 типа покупателей
- Терпение, реплики-подсказки и встречные предложения
- Подделки, осмотр товара и оценка стоимости
- События дня: дождь, ярмарка, статья в газете
- Рекорд сохраняется в браузере

## Стек

JavaScript. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/flea-market.git
cd flea-market
python3 -m http.server 8000
```
